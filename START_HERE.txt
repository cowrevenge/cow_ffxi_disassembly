WHAT THIS IS
  The complete research corpus for the retail FINAL FANTASY XI client
  (FFXiMain.dll): static disassembly passes, DAT/ROM analysis, evidence dumps,
  and all tooling that produced them. The remake itself lives elsewhere
  (C:\Cow_Kuluu_ffxi-engine). Convention rules + binary facts + pass table:
  README.md in this folder. Current research state: Disassembly_Docs/summary.md.

RULES OF THE HOUSE
  1. Never commit DATs or the extracted tree (see .gitignore). Retail client never goes in git.
  2. No credentials/tokens; prose install paths (C:\PhoenixXI\...) are machine refs, fine.
  3. One canonical copy of each tool: Disassembly_Tools/ top level. The old read-only
     snapshot (legacy_ffxi_disasm/) was deleted 2026-10-08 — do not recreate it.
  4. Vault = game-system knowledge ONLY. No session logs, work ledgers, agent briefs,
     or implementation-state docs (they rot and fork). That class was purged 2026-10-08;
     kuluu status lives in the engine repo/beads. Docs that ARE kept carry a freshness
     stamp: date last verified against which build.
  5. New docs land in Disassembly_Docs/, new scanners in Disassembly_Tools/. Keep START_HERE current.
